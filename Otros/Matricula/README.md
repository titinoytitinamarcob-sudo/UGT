# Mamerto · Consulta Transporte

Ruta configurada: `/UGT/Matricula/`

Icono externo: https://titinoytitinamarcob-sudo.github.io/UGT/Otros/mamerto.png

Sube `index.html`, `manifest.json`, `service-worker.js` y `icons/` a la carpeta publicada en `/UGT/Matricula/`. GitHub Pages debe servir la página por HTTPS.

iPhone: Safari → Compartir → Añadir a pantalla de inicio.
Android: Chrome → menú ⋮ → Instalar aplicación o Añadir a pantalla de inicio, si aparece.

La página requiere aceptación expresa del aviso antes de abrir la consulta oficial. No es una aplicación oficial del Ministerio.
